Лабораторная работа №2. Базовые и продвинутые возможности CSS
  Цель: Научиться подключать стили, работать с селекторами, типографикой, цветами,
отступами, позиционированием и псевдоклассами.
  Задание:
Оформить страницу из ЛР №1 с помощью внешнего CSS файла (style.css). Реализовать:
* Основной стиль – во внешнем файле; 1 элемент с inline стилями; 1 правило во
внутреннем блоке style.
* CSS переменные в :root для цветов и шрифтов.
* Примеры позиционирования: static, relative, absolute.
* Состояния элементов: :hover, :active, :focus, :visited.
* Контрастность текста не менее 4.5:1.

Вариант 13. Тема «Волонтёр и социальный активист» (эффект «пульсации» призыва
к действию)
Добавьте псевдоэлемент к кнопке отправки формы, имитирующий «пульсирующее сердце»
(через @keyframes). При :hover меняйте цвет кнопки на красный. При :active слегка
смещайте кнопку вниз. В переменных: основной – белый, акцент – красный. Inline-стиль:
margin-bottom: 20px для секции «Навыки». Внутренний блок: стили для подвала (footer) –
выравнивание и размер шрифта.
